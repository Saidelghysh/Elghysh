# زاد الآخرة 🕌 — خير الزاد ليوم المعاد

موقع إسلامي شامل (HTML/CSS/JavaScript خالص، بدون أي إطار عمل) يضم:

- 🏠 الصفحة الرئيسية (بانر صدقة جارية + مكتبة رئيسية + آخر التلاوات)
- 📖 القرآن الكريم كاملًا (114 سورة) بأصوات عدة قراء
- 🎧 المكتبة الصوتية / التلاوات
- 🔊 حفلات خارجية
- ⭐ الابتهالات والتواشيح
- ✍️ خواطر إيمانية
- 📿 الأذكار (صباح / مساء / بعد الصلاة / نوم) مع عداد تكرار تفاعلي
- 🕌 الأذان
- 💚 صدقة جارية (يمكن إضافة أسماء)
- 🤍 المفضلة (محفوظة في متصفحك)
- ⚙️ إعدادات (القارئ الافتراضي، طريقة حساب المواقيت)
- مواقيت صلاة حقيقية تُحسب تلقائيًا حسب موقع الزائر (Aladhan API)
- مشغل صوت ثابت أسفل الصفحة يعمل في كل الصفحات

## المصادر المستخدمة (مجانية بالكامل، بدون مفاتيح API)
- الصوتيات القرآنية: [mp3quran.net](https://www.mp3quran.net/api) (بث مباشر لملفات mp3 حسب القارئ ورقم السورة)
- مواقيت الصلاة: [Aladhan API](https://aladhan.com/prayer-times-api)
- إذاعة القرآن الكريم المباشرة: راديو ستريم عام
- الأذان: [islamcan.com](https://www.islamcan.com/audio/adhan/)
- الصور: صور حرة الاستخدام من Wikimedia Commons

> ملاحظة: قسم "الابتهالات" و"حفلات خارجية" يعرضان حاليًا محتوى تجريبيًا (تلاوات مختارة) لعدم توفر مصدر برمجي موحّد وموثوق لهذا النوع من المحتوى مجانًا، ويمكن استبدالها لاحقًا بسهولة عبر تعديل المصفوفات الموجودة في كل صفحة.

## التشغيل محليًا
لا يحتاج المشروع أي تثبيت. يكفي فتح `index.html` في المتصفح، أو تشغيل خادم محلي بسيط (مستحسن حتى تعمل مواقيت الصلاة وربط الصفحات بشكل صحيح):

```bash
cd zad-alakhera
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## رفع المشروع على GitHub ونشره مجانًا (GitHub Pages)

1. أنشئ مستودعًا جديدًا فارغًا على GitHub (بدون README) باسم مثل `zad-alakhera`.
2. من داخل مجلد المشروع نفّذ الأوامر التالية:

```bash
cd zad-alakhera
git init
git add .
git commit -m "أول نسخة من موقع زاد الآخرة"
git branch -M main
git remote add origin https://github.com/USERNAME/zad-alakhera.git
git push -u origin main
```

استبدل `USERNAME` باسم حسابك على GitHub.

3. لتفعيل النشر المجاني (GitHub Pages):
   - افتح المستودع على GitHub
   - اذهب إلى **Settings → Pages**
   - في خانة **Branch** اختر `main` والمجلد `/root`، ثم اضغط **Save**
   - بعد دقيقة أو دقيقتين سيكون الموقع متاحًا على رابط مثل:
     `https://USERNAME.github.io/zad-alakhera/`

## التخصيص السريع
- لإضافة قارئ جديد: أضف سطرًا جديدًا في `RECITERS` داخل `js/quran-data.js` (رابط السيرفر من mp3quran.net).
- لتغيير الألوان: عدّل متغيرات `:root` في أعلى ملف `css/style.css`.
- لإضافة اسم لصدقة جارية دائمة على الرئيسية: عدّل مصفوفة `sadaqaNames` داخل `index.html`.
